# 1. EMA 与卡尔曼滤波

传感器数据平滑的两把瑞士军刀：EMA（Exponential Moving Average，指数移动平均）是一个参数、O(1) 开销的递归低通；卡尔曼滤波（Kalman Filter）是带模型、增益自适应的最优线性估计器。本文覆盖原理、公式、适用场景与可直接移植的 C/C++ 实现。

## 【核心精简提纲】

### 记忆主干

**EMA**：$y_n = \alpha x_n + (1-\alpha)\,y_{n-1}$，一个参数 $\alpha$，一个浮点状态，最便宜的低通。

**卡尔曼**：预测 + 更新两步循环。预测 $x_k^- = Fx_{k-1}$，$P_k^- = FPF^T + Q$；更新 $K = P^-H^T(HP^-H^T + R)^{-1}$，$x_k = x_k^- + K(z_k - Hx_k^-)$，$P_k = (I-KH)P_k^-$。

**两个等价关系**（深挖结论）：一维常数模型卡尔曼稳态增益收敛为常数 $K_\infty$，退化为 EMA（$\alpha = K_\infty$）；恒速模型卡尔曼稳态退化为 α-β 滤波器。

**调参铁律**：Q/R 比值决定行为——比值大信观测（跟随快、抖），比值小信模型（平滑、滞后）。R 可实测（静止采样方差），Q 从 R/100 起步调。P0 取大（1~100）加速启动收敛。

### 核心要点清单

- EMA 首帧直接透传，避免初始 0 拖慢收敛
- $\alpha = 2/(N+1)$ 等价于周期 N 的滑动平均（SMA）
- $\alpha$ 常用 0.1~0.3：跟随 vs 平滑的折中
- 截止频率 $f_c \approx \frac{\alpha}{2\pi(1-\alpha)\,T_s}$
- 卡尔曼 1D 常数模型只需 4 个浮点变量（q, r, x, p）
- 无 FPU 的 MCU 建议定点实现，或用 double 防 P 矩阵长期运行退化
- 卡尔曼可估计不可观测状态（如从位置测距估出速度）
- 多传感器融合是卡尔曼的强项（扩展 H 矩阵），EMA 只能单源

### 关键结论 / 流程

| 场景 | 选择 |
|------|------|
| 资源受限、噪声平稳、只要平滑值 | EMA |
| 有运动模型、要估计速度、多传感融合 | 卡尔曼 |
| 先快速验证 | 从 EMA 起步，效果不够再上卡尔曼 |

## 1.1 EMA 指数移动平均

### 1.1.1 原理与公式

EMA 是一阶 IIR 低通滤波器，新输出 = 新输入与旧输出的加权和：

$$
y_n = \alpha\, x_n + (1-\alpha)\, y_{n-1}, \qquad 0 < \alpha \le 1
$$

- $\alpha$ 越大，越信任新测量：跟随快、噪声残留多、滞后小
- $\alpha$ 越小，越平滑：噪声压制好、滞后大
- 递归结构只需保存 1 个状态变量，每次更新 1 次乘 1 次加，O(1) 时间与空间

与滑动平均（SMA）的关系：周期 N 的 SMA 等价于 $\alpha = \dfrac{2}{N+1}$ 的 EMA（截止特性近似）。

频率视角（时间常数与截止频率）：

$$
\tau = \frac{1-\alpha}{\alpha}\, T_s, \qquad f_c \approx \frac{\alpha}{2\pi(1-\alpha)\, T_s}
$$

$T_s$ 为采样周期。例如 100 Hz 采样、$\alpha = 0.2$，则 $f_c \approx 4$ Hz——高于此频率的成分被显著衰减。

### 1.1.2 参数与调参

- **起步值**：$\alpha = 0.2$，按需求往两头调
- **首帧处理**：第一个样本直接透传（`ready` 标志），避免以 0 为初值导致的前若干帧明显爬升
- **等价换算**：想"等效 N 点平均"就用 $\alpha = 2/(N+1)$；想"约 τ 秒的时间常数"就用 $\alpha = 1/(1+\tau/T_s)$

### 1.1.3 适用场景

- ADC 原始值平滑（温度、电压、电流采样）
- 缓慢变化量的读数稳定（温湿度、压力、液位）
- UI 数值显示去抖（传感器读数显示在屏幕上跳动）
- 噪声统计平稳、信号带宽远低于采样率的任何低成本平滑
- 适合没有 FPU、算力极低的 MCU——定点化后仅移位加乘

局限：权重固定，噪声变大不会自动多平滑；无模型，估计不了未测量的量。

## 1.2 卡尔曼滤波

### 1.2.1 原理：预测-更新两步循环

卡尔曼滤波假设系统是**线性高斯状态空间模型**：

$$
x_k = F x_{k-1} + B u_k + w_k, \qquad w_k \sim \mathcal{N}(0, Q)
$$

$$
z_k = H x_k + v_k, \qquad v_k \sim \mathcal{N}(0, R)
$$

核心思想：**预测**（用运动模型外推）+ **更新**（用测量修正），增益 $K$ 按当前估计误差协方差 $P$ 自动调节——估计越没底，越信测量；估计越有底，越信模型。这就是它优于固定权重滤波的本质。

### 1.2.2 通用五公式

预测（时间更新）：

$$
\hat{x}_k^- = F \hat{x}_{k-1} + B u_k
$$

$$
P_k^- = F P_{k-1} F^T + Q
$$

更新（测量更新）：

$$
K_k = P_k^- H^T \left( H P_k^- H^T + R \right)^{-1}
$$

$$
\hat{x}_k = \hat{x}_k^- + K_k \left( z_k - H \hat{x}_k^- \right)
$$

$$
P_k = \left( I - K_k H \right) P_k^-
$$

符号速记：$\hat{x}_k^-$ 为先验估计（预测值），$z_k - H\hat{x}_k^-$ 叫**新息**（innovation，测量与预测的差），$K_k$ 为卡尔曼增益（0~1 之间的权重向量）。

### 1.2.3 一维常数模型（最常用特例）

对"真实值缓慢变化"的标量测量：$F = H = 1$，五公式坍缩成四行：

$$
P^- = P + Q, \qquad K = \frac{P^-}{P^- + R}
$$

$$
\hat{x} = \hat{x} + K\,(z - \hat{x}), \qquad P = (1 - K)\, P^-
$$

只需 4 个浮点状态（q, r, x, p），嵌入式最常用的形态。

### 1.2.4 参数 Q/R 的含义与调参

- **R**（观测噪声方差）：传感器噪声，**可实测**——静止放置采集 N 个样本，求方差 $\frac{1}{N}\sum(z_i-\bar z)^2$。卡曼滤波对 R 不那么敏感，测个量级即可
- **Q**（过程噪声方差）：模型不确定性 / 真实值变化快慢。真实值变化越快，Q 越大。无先验时从 $Q = R/100$ 起步，逐步加大直到滤波不再滞后
- **Q/R 比值**是真正的旋钮：比值大 → K 大 → 跟随快、噪声多；比值小 → K 小 → 平滑、滞后大
- **P0**（初始协方差）：取大值（1~100），让滤波器初期信任测量、快速收敛；不用精确设置

### 1.2.5 适用场景

- IMU 姿态融合（陀螺仪积分 + 加速度计修正，互补滤波的升级版）
- GPS + 惯导 / 里程计融合定位（多传感器，不同噪声特性）
- 目标跟踪（恒速/恒加速模型，可输出位置与速度两个状态）
- 锂电池 SOC 估计、雷达/激光测距平滑
- 任何"有运动模型 + 噪声可建模 + 需要估计不可观测状态"的问题

局限：线性高斯假设——非线性系统需扩展卡尔曼（EKF）/ 无迹卡尔曼（UKF）；计算量比 EMA 高一个量级，需要浮点支持。

## 1.3 对比与选型

| 维度 | EMA | 卡尔曼 |
|------|-----|--------|
| 模型要求 | 无 | 状态方程 + 噪声 Q/R |
| 参数数量 | 1 个 α | 至少 Q、R 两个 |
| 计算开销 | 1 乘 1 加 | 1D 约 6 次浮点运算，2D 数十次 |
| 增益行为 | 固定常数 | 自适应（随 P 收敛，噪声变化可重调） |
| 状态估计 | 仅平滑值 | 可估计速度等不可观测状态 |
| 多源融合 | 不支持 | 天然支持（扩展 H 矩阵） |
| 稳态退化 | — | 1D 常数模型 → EMA；恒速模型 → α-β 滤波器 |

**深挖·稳态等价**：Q、R 固定时，一维卡尔曼的增益单调收敛到常数 $K_\infty$（$K$ 只依赖 $Q/R$ 比值），更新式变为 $\hat{x} = (1-K_\infty)\hat{x} + K_\infty z$——这正是 $\alpha = K_\infty$ 的 EMA。所以 EMA 可以看作"增益被提前算好的卡尔曼"，两者的鸿沟没有想象中大。

**选型建议**：项目初期、噪声平稳、需求只是"读数好看"→ 直接 EMA；需要估计速度、多传感器打架、或有明确的运动模型 → 卡尔曼。

## 1.4 代码实践

### 1.4.1 EMA —— C 实现

```c
/* ema_filter.h */
#ifndef EMA_FILTER_H
#define EMA_FILTER_H

#include <stdint.h>

typedef struct {
    float   alpha;   /* 平滑系数 (0, 1]，越大越信新测量 */
    float   y;       /* 上一次输出 */
    uint8_t ready;   /* 首帧透传标志 */
} ema_filter_t;

static inline void ema_init(ema_filter_t *f, float alpha)
{
    f->alpha = alpha;
    f->y     = 0.0f;
    f->ready = 0;
}

static inline float ema_update(ema_filter_t *f, float x)
{
    if (!f->ready) {          /* 首帧直接透传，避免从 0 爬升 */
        f->y = x;
        f->ready = 1;
        return f->y;
    }
    f->y = f->alpha * x + (1.0f - f->alpha) * f->y;
    return f->y;
}

#endif /* EMA_FILTER_H */
```

调用示例：`ema_filter_t f; ema_init(&f, 0.2f); val = ema_update(&f, adc_raw);`

### 1.4.2 一维卡尔曼 —— C 实现

```c
/* kalman1d.h */
#ifndef KALMAN1D_H
#define KALMAN1D_H

typedef struct {
    float q;   /* 过程噪声方差：真实值变化快慢 */
    float r;   /* 观测噪声方差：传感器噪声，可实测 */
    float x;   /* 状态估计 */
    float p;   /* 误差协方差 */
} kalman1d_t;

static inline void kalman1d_init(kalman1d_t *k, float q, float r, float x0)
{
    k->q = q;
    k->r = r;
    k->x = x0;
    k->p = 1.0f;   /* P0 取大，让首帧快速信任测量 */
}

static inline float kalman1d_update(kalman1d_t *k, float z)
{
    float kk;                          /* 卡尔曼增益 */

    k->p += k->q;                      /* 预测：P⁻ = P + Q（常数模型 F=1） */
    kk    = k->p / (k->p + k->r);      /* 增益：K = P⁻/(P⁻ + R) */
    k->x += kk * (z - k->x);           /* 更新：x̂ = x̂⁻ + K(z − x̂⁻) */
    k->p *= (1.0f - kk);               /* 更新：P = (1 − K)P⁻ */

    return k->x;
}

#endif /* KALMAN1D_H */
```

调用示例：`kalman1d_t k; kalman1d_init(&k, 0.001f, 0.01f, adc_raw); val = kalman1d_update(&k, adc_raw);`

### 1.4.3 恒速二维卡尔曼 —— C++ 实现

状态 $x = [\text{pos}, \text{vel}]^T$，模型 $F = \begin{bmatrix}1 & \Delta t\\ 0 & 1\end{bmatrix}$，$H = [1, 0]$，白噪声加速度模型 $Q = q \cdot G G^T$（$G = [\Delta t^2/2, \Delta t]^T$）。用于测距/测位平滑，可同时输出速度。

```cpp
// kalman2d.hpp —— 恒速模型（白噪声加速度），位置 + 速度两状态
#ifndef KALMAN2D_HPP
#define KALMAN2D_HPP

class Kalman2D {
public:
    // q: 过程噪声（加速度不确定性）  r: 观测噪声方差  dt: 采样周期(秒)
    Kalman2D(float q, float r, float dt)
        : q_(q), r_(r), dt_(dt) {
        reset(0.0f, 0.0f);
    }

    void reset(float pos, float vel) {
        x_[0] = pos;
        x_[1] = vel;
        p_[0][0] = p_[1][1] = 1.0f;   // 大 P0，加速启动收敛
        p_[0][1] = p_[1][0] = 0.0f;
    }

    // 输入测量位置 z，返回滤波后位置；速度可经 vel() 读取
    float update(float z) {
        predict();

        // ---- 更新（H = [1, 0]，新息 y = z − x[0]）----
        float s  = p_[0][0] + r_;      // S = H·P⁻·Hᵀ + R
        float k0 = p_[0][0] / s;       // K = P⁻·Hᵀ / S
        float k1 = p_[1][0] / s;
        float y  = z - x_[0];

        x_[0] += k0 * y;
        x_[1] += k1 * y;

        // P = (I − K·H)·P⁻，P 对称只需更新三角
        float p00 = (1.0f - k0) * p_[0][0];
        float p01 = (1.0f - k0) * p_[0][1];
        float p10 = p_[1][0] - k1 * p_[0][0];
        float p11 = p_[1][1] - k1 * p_[0][1];
        p_[0][0] = p00; p_[0][1] = p01;
        p_[1][0] = p10; p_[1][1] = p11;

        return x_[0];
    }

    float pos() const { return x_[0]; }
    float vel() const { return x_[1]; }

private:
    void predict() {
        const float dt  = dt_;
        const float d2  = dt * dt;

        // x⁻ = F·x：pos += dt·vel
        x_[0] += dt * x_[1];

        // P⁻ = F·P·Fᵀ + Q，Q = q·G·Gᵀ，G = [dt²/2, dt]ᵀ
        const float p00 = p_[0][0] + dt * p_[1][0];   // (F·P) 三角元素
        const float p01 = p_[0][1] + dt * p_[1][1];
        const float p11 = p_[1][1];

        p_[0][0] = p00 + dt * p01 + q_ * d2 * d2 / 4.0f;   // Q[0][0] = q·dt⁴/4
        p_[0][1] = p01 + q_ * dt * d2 / 2.0f;              // Q[0][1] = q·dt³/2
        p_[1][0] = p_[1][0] + dt * p11 + q_ * dt * d2 / 2.0f;
        p_[1][1] = p11 + q_ * d2;                          // Q[1][1] = q·dt²
    }

    float q_, r_, dt_;
    float x_[2];      // [pos, vel]
    float p_[2][2];   // 误差协方差矩阵
};

#endif // KALMAN2D_HPP
```

调用示例：

```cpp
Kalman2D kf(0.01f, 0.25f, 0.02f);   // 50 Hz 采样，观测噪声 σ=0.5
float pos = kf.update(tof_distance);
float vel = kf.vel();                // 不可观测状态也能估出来
```

## 1.5 工程踩坑

- **无 FPU 的 MCU**：float 乘加也有库开销，可把全部量按 Q15/Q12 定点化；EMA 只需移位加乘，最容易
- **P 矩阵长期退化**：卡尔曼运行数小时后 P 可能下溢为 0，增益失去自适应能力——定期重设或关键路径用 double
- **dt 必须真实**：恒速模型里 dt 用实际流逝时间（如 RTC/定时器差值），用"假设的固定周期"在负载抖动时会失真
- **首帧与初值**：EMA 首帧透传；卡尔曼 P0 取大；不要用 0 做初值（目标跟踪常见错法）
- **先验证再升级**：同一数据先跑 EMA，若滞后不可接受或需要速度输出，再换卡尔曼——两种实现的输出可以放在同一调试通道对比（参考 [[C-Linux生态/04.调试与优化/1. gdb|GDB 调试]] 看实时变量）
